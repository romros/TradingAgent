# Auditoria d'eines proposades — 2026-08-02

## Mètode i límits

Revisió documental de repositoris i documentació primària, accedits el 2026-08-02.
No s'ha executat codi de tercers ni s'ha fet cap instal·lació. Criteris: encaix amb
el problema, maduresa, dependències/serveis, privacitat, copyright, superfície
d'execució, reversibilitat i valor incremental sobre SQLite FTS5.

Els noms `claude-video`, `speech-to-speech` i `Vibe-Trading` són ambigus. Aquesta
auditoria identifica explícitament el projecte avaluat; un projecte diferent exigeix
una fitxa nova. Una estrella, una demo o una llicència de codi no concedeixen drets
sobre el contingut ingerit.

## Decisions

| Eina identificada | Ús proposat | Riscos i cost | Decisió |
|---|---|---|---|
| `jordanrendric/claude-video-vision` (la coincidència localitzada per “claude-video”) | Analitzar vídeo amb frames i transcripció | Identitat inicial ambigua; extracció de media de tercers; cost de model i risc de conservar frames/transcripcions | **No incorporar.** Reavaluar només amb un vídeo propi/autoritzat i un test de qualitat contra notes manuals. |
| `Panniantong/Agent-Reach` | Accés multicanal i subtítols via eines externes | Instal·lador ampli, múltiples binaris/API/cookies/proxies; superfície molt superior a la necessitat; dependència indirecta de `yt-dlp` | **Rebutjar per ara.** Si cal una font web concreta, usar un adaptador mínim i revisat. |
| `jdepoix/youtube-transcript-api` | Recuperar subtítols existents sense clau | API no oficial susceptible a bloqueig/canvis; termes i copyright depenen del vídeo; no aporta títol; incentiva conservar text complet | **Pilot opcional, no instal·lat.** Només captura temporal a `/tmp`, destil·lació amb timestamps i eliminació; fallback manual. |
| `huggingface/speech-to-speech` | Agent de veu local STT→LLM→TTS | Models pesants, GPU/latència i servidor de temps real; no resol catalogació ni retrieval; pot enviar text a un endpoint LLM | **Fora d'abast.** Reavaluar per accessibilitat o narració pròpia, independent del catàleg. |
| `OpenCut-app/OpenCut` | Edició de vídeos propis | La branca principal declara una reescriptura; editor/infra web molt més gran que el nucli; automatització/headless encara anunciada | **Diferir.** Exportar guions estàndard; provar una versió fixada quan headless sigui estable. No integrar servidor. |
| `HKUDS/DeepTutor` | Tutor personalitzat amb RAG | Duplica ingestió, memòria, UI i agents; requereix proveïdors/model, Python+Node o contenidor; execució de codi generat configurable; RAG no justificat | **No incorporar.** Prendre només idees pedagògiques; reconsiderar després del benchmark i d'un threat model. |
| `HKUDS/Vibe-Trading` | Recerca/backtest agentic | Fora del límit educatiu; dades, LLM, memòria i eines d'anàlisi amplien risc; proximitat amb trading pot confondre recerca i execució | **Rebutjar.** No connectar a SQCLI, BrokerageService ni execució. |

## Gates de reconsideració

1. Cas d'ús i corpus autoritzat concret.
2. Versió o commit fixat, llicència i dependències inventariades.
3. Prova efímera aïllada, sense secrets ni cookies personals.
4. Comparació amb el flux manual/stdlib sobre qualitat, temps i cost.
5. Threat model i política d'esborrat; cap media de tercers a Git.
6. Per embeddings/RAG: 50 preguntes jutjades i millora material sobre FTS5.
