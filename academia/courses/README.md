# Cursos propis

Cada curs es compon de lliçons petites i verificables:

1. pregunta concreta;
2. prerequisits;
3. fonts;
4. explicació;
5. demo SQCLI/GUI;
6. experiment reproduïble;
7. errors freqüents;
8. exercici;
9. resposta/gate;
10. estat de confiança.

Formats previstos: Markdown com a font canònica, diapositives/HTML derivades i guió
de vídeo. Els vídeos propis es generaran des del guió versionat, no al revés.
