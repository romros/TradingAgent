# Política de media

Aquest directori conserva manifests i referències, no còpies permanents de vídeos de
tercers. Les descàrregues temporals per obtenir frames o transcripció van a `/tmp` i
s'eliminen després de destil·lar el coneixement.

Per a vídeos propis es conservaran guió, fonts, projecte de gravació i checksum del
resultat. Els fitxers grans s'emmagatzemaran fora de Git amb una política explícita.
